# AX-HUB 사용자 포털 — 컴포넌트 카탈로그

> 대상 독자: **디자이너 · 퍼블리셔 · 초급 프론트 개발자**
> 위치: `src/components/` (Vue 3 `<script setup>`). 스타일은 전역 `src/styles.css` 클래스를 사용합니다(퍼블리싱가이드.md 참고).
> 이 문서는 각 컴포넌트의 **역할 · props · emit · 주요 사용처 · 비고**를 정리합니다. 값은 모두 실제 소스 기준.

## 한눈에 보기 (18개)

| 컴포넌트 | 유형 | 여는 방식 | 주요 사용처 |
|----------|------|-----------|-------------|
| `Icon` | 표시(아이콘) | — | 전 화면 공용 |
| `StatusPill` | 표시(상태 pill) | — | AgentRun, Knowledge |
| `Steps` | 표시(진행 단계) | — | Permissions |
| `AgentInfoModal` | 모달 | prop(agent) | Agents |
| `AgentFab` | 플로팅 액션 | 항상 표시 | App.vue(전역, 시스템 페이지 제외) |
| `BuilderModal` | 모달(런처) | prop | AgentFab |
| `ChatbotModal` | 플로팅 팝업 | 상태 | AgentFab |
| `RequestModal` | 모달(폼) | **store.modal** | App.vue(전역) |
| `DenyModal` | 모달(폼) | **store.denyModal** | App.vue(전역) |
| `PromptDialog` | 모달(입력) | prop + emit | Agents, FolderPickerModal |
| `FolderPickerModal` | 모달 | prop(agent) | Agents |
| `KnowledgeTreeNode` | 표시(재귀 트리) | prop(node) | Knowledge |
| `KnowledgeChat` | 복합(RAG 챗) | prop(items…) | Knowledge |
| `ReportModal` | 모달(폼) | prop(agent, messages) | AgentRun |
| `DetailModal` | 모달(상세) | prop(detail) | ItOps, SysMonitor, Knowledge |
| `SettingsModal` | 모달(테마) | emit(close) | App.vue |
| `ApprovalLine` | 입력(결재선) | **v-model** | AccessRequest |
| `CardRail` | 래퍼(레일) | prop(grid) | **미사용(임포트 없음)** |

> 팝업 여는 방식은 크게 3가지: ① **prop 으로 데이터 주입 + `@close` emit**(AgentInfoModal, DetailModal 등), ② **store 전역 상태로 열기**(RequestModal=`store.modal`, DenyModal=`store.denyModal`), ③ **로컬 ref + emit**(PromptDialog, SettingsModal).

## 1. Icon

- **역할**: 24×24 viewBox 라인 SVG 아이콘. `name` 으로 path 를 선택해 그림. `stroke="currentColor" fill="none"` 이라 **부모 `color` 로 색 지정**.
- **props**: `name: String`(아이콘 키), `size: Number|String = 18`.
- **emit**: 없음.
- **주요 사용처**: 전 컴포넌트/페이지.
- **비고**: 사용 가능한 `name` 38종 —
  `home, bot, book, shield, chat, search, send, back, zap, doc, clock, play, check, arrow, users, plus, x, menu, dots, attach, tool, layers, trash, share, flag, megaphone, cpu, chevron, folder, star, collapse, expand, grid, list, download, edit, bell, gear`.
  목록에 없는 `name` 을 넘기면 아무것도 안 그려집니다(빈 SVG). 채움형 아이콘은 CSS 에서 `svg { fill: currentColor }` 로 처리(예: `.fav-btn.on`, `.tabs .tab-ic`).

```html
<Icon name="plus" :size="14" />
<span class="star-ic"><Icon name="star" :size="16" /></span>   <!-- 부모 color 로 채움 -->
```

## 2. StatusPill

- **역할**: 권한(소유) 상태값을 색 pill 로 표시. `permMeta[perm]` 로 라벨·클래스를 매핑.
- **props**: `perm: String`(`owner|granted|pending|none|denied|expired`), `small: Boolean`.
- **emit**: 없음.
- **주요 사용처**: `AgentRun.vue`(내 권한), `Knowledge.vue`(지식 카드/행).
- **비고**: 매핑표(`src/shared/constants/enums.js` PERM_META) —

  | perm | 라벨 | 클래스 |
  |------|------|--------|
  | `owner` | 내 소유 | `.pill-owner`(블루) |
  | `granted` | ● 사용중 | `.pill-active`(그린) |
  | `pending` | 요청중 | `.pill-pending`(골드) |
  | `none` | 권한없음 | `.pill-none`(회색) |
  | `denied` | 반려 | `.pill-denied`(레드) |
  | `expired` | 만료 | `.pill-none`(회색) |

```html
<StatusPill :perm="agent.perm" />
<StatusPill :perm="k.perm" small />
```

## 3. Steps

- **역할**: 권한 요청 처리 진행 단계(요청 제출 → 승인자 검토 → 완료/반려)를 가로 스텝퍼로 표시.
- **props**: `status: String`(`pending | approved | denied`).
- **emit**: 없음.
- **주요 사용처**: `Permissions.vue`(요청/승인 행).
- **비고**: status 에 따라 3단계 상태(`done`/`now`/`fail`)를 내부 계산. `approved`=3단계 모두 done, `denied`=마지막 fail(레드), `pending`=2단계 now(골드). 사용 클래스 `.steps/.step/.step-line`.

```html
<Steps :status="r.status" />
```

## 4. AgentInfoModal

- **역할**: Agent 상세 정보 팝업. 모델/카테고리/지식/버전/실행수, **활용 도구별 권한 상태 칩**(클릭 시 요청/취소 확인 알럿), 추천 질문 표시. 권한 충족 시 "이 에이전트 사용"(실행), 부족 시 "권한 요청"(RequestModal 오픈).
- **props**: `agent: Object`.
- **emit**: `close`.
- **주요 사용처**: `Agents.vue`(카드 클릭/메뉴 → `infoAgent`).
- **비고**: 내부에서 store 액션 사용(`openRun`, `requestResource`, `cancelRequest`, `resourcePerm`, `agentReady`, `openRequest`). 도구 칩은 `.res-chip` + `.res-{granted|pending|none|denied}`. 확인 알럿은 `.overlay.confirm-scrim` + `.confirm-modal`. 사용 클래스 `.modal-info`, `.info-head/.info-grid/.info-cell`, `.ready-pill`, `.ex-list`.

```html
<AgentInfoModal v-if="infoAgent" :agent="infoAgent" @close="infoAgent = null" />
```

## 5. AgentFab

- **역할**: 우측 세로 중앙 **드래그 이동형 플로팅 버튼**. 열면 3개 생성 액션(Agent 빌더 / 지식 생성 / 챗봇) 노출. embed 액션은 BuilderModal(런처)로, chat 은 ChatbotModal 로 연결.
- **props**: 없음.
- **emit**: 없음(내부에서 BuilderModal/ChatbotModal 직접 렌더).
- **주요 사용처**: `App.vue` — 전역. 단, 시스템 페이지(`sysmon, itops, computeruse, daily`)에서는 `v-if` 로 숨김.
- **비고**: 포인터 드래그로 위치 이동(clamp 로 화면 내 제한), 드래그 직후 클릭 억제. 평상시 반투명(opacity .48), 사용 중 진하게. 사용 클래스 `.fab-dock/.fab-main/.fab-action/.fab-avatar(.tone-*)`.

```html
<AgentFab v-if="!['sysmon','itops','computeruse','daily'].includes(store.page)" />
```

## 6. BuilderModal

- **역할**: 외부 빌더(Agent 빌더/지식 생성) **실행 런처**. 보안상 iframe 삽입 불가 → 별도 팝업 창으로 실행하거나 새 탭으로 이동.
- **props**: `title: String`, `url: String`, `ico: String = 'book'`, `tone: String = 'green'`.
- **emit**: `close`.
- **주요 사용처**: `AgentFab.vue`.
- **비고**: `window.open(...popup...)` 실행, 차단 시 토스트 경고 후 "새 탭에서 열기" 링크 제공. 사용 클래스 `.launch-modal/.launch-ic(.tone-*)/.launch-url/.launch-actions`.

```html
<BuilderModal :title="b.title" :url="b.url" :ico="b.ico" :tone="b.tone" @close="builder = null" />
```

## 7. ChatbotModal

- **역할**: 우하단 **플로팅 Q&A 챗봇 패널**. 화면(메시지 목록 + 입력)만 담당하고, 답변 생성은 `features/chatbot/services/chatbotService.getReply()` 가 담당(역할 분리).
- **props**: 없음.
- **emit**: `close`.
- **주요 사용처**: `AgentFab.vue`(챗봇 액션).
- **비고**: 전송 시 타이핑(`.typing`) 연출 후 답변. 사용 클래스 `.cb-panel/.cb-head/.cb-body/.cb-input`, 말풍선은 공용 `.msg/.bubble`.

## 8. RequestModal

- **역할**: **권한 요청 폼** 모달. 대상이 Agent 면 실행에 필요한 미보유 도구 목록을, 지식이면 요청 권한 종류(열람/사용/공유)를 선택. 사용 기간·요청 사유·(자동 지정)승인자 입력 후 등록.
- **props**: 없음 — **전역 `store.modal` 로 열림**(`{ item, targetType }`).
- **emit**: 없음(닫기는 `store.modal = null`).
- **주요 사용처**: `App.vue` 에 전역 배치(`v-if="store.modal"`). 여는 곳: `openRequest('agent'|'knowledge', item)`(예: AgentInfoModal 의 "권한 요청").
- **비고**: 내부 store 액션 `submitRequest`, `resourcePerm`. Agent 는 요청할 도구가 없으면 등록 버튼 비활성. 사용 클래스 공용 `.modal/.field/.modal-actions`, `.req-tools/.req-tool`.

```html
<!-- App.vue (전역) -->
<RequestModal v-if="store.modal" />
<!-- 여는 쪽: store 액션 -->
openRequest('agent', agentObj)   // store.modal = { item, targetType:'agent' }
```

## 9. DenyModal

- **역할**: 승인자용 **요청 반려 폼**. 반려 사유(요청자에게 그대로 전달)를 입력하고 반려 확정.
- **props**: 없음 — **전역 `store.denyModal` 로 열림**(`{ requester, dept, targetName, … }`).
- **emit**: 없음(닫기는 `store.denyModal = null`).
- **주요 사용처**: `App.vue` 전역 배치(`v-if="store.denyModal"`). 확정 시 `confirmDeny(reason)`.
- **비고**: 사용 클래스 공용 `.modal/.field`, 확정 버튼 `.btn-danger`.

```html
<DenyModal v-if="store.denyModal" />
```

## 10. PromptDialog

- **역할**: **공통 한 줄 입력 팝업**(브라우저 `prompt()` 대체). 폴더 생성/이름 변경 등 여러 곳에서 재사용. 마운트 시 입력에 자동 포커스, Enter 로 확인.
- **props**: `title = '입력'`, `label = ''`, `placeholder = ''`, `value = ''`(초기값), `confirmText = '확인'`.
- **emit**: `confirm(value)` — 공백이면 무시, `close`.
- **주요 사용처**: `Agents.vue`(새 폴더), `FolderPickerModal.vue`(새 폴더 만들어 이동).
- **비고**: 값 검증은 호출부 책임(트림된 문자열만 emit). 사용 클래스 `.modal-prompt/.prompt-title/.prompt-field`.

```html
<PromptDialog v-if="showNewFolder" title="새 폴더" label="폴더 이름"
  placeholder="예: 마케팅 봇" confirm-text="만들기"
  @confirm="onCreate" @close="showNewFolder = false" />
```

## 11. FolderPickerModal

- **역할**: Agent 를 **폴더로 이동**하는 팝업. 기존 폴더 선택 또는 PromptDialog 로 새 폴더를 만들어 즉시 이동.
- **props**: `agent: Object`.
- **emit**: `close`.
- **주요 사용처**: `Agents.vue`(`folderFor`).
- **비고**: store 액션 `moveAgentToFolder`, `addFolder`. 내부에 PromptDialog 를 중첩 사용. 사용 클래스 `.modal-folder/.fp-list/.fp-item(.on)/.fp-new`.

```html
<FolderPickerModal v-if="folderFor" :agent="folderFor" @close="folderFor = null" />
```

## 12. KnowledgeTreeNode

- **역할**: 지식 컬렉션 **재귀 트리 노드**. 자식이 있으면 폴더 아이콘 + 펼침 캐럿, 없으면 문서 아이콘. 깊이에 따라 들여쓰기(`8 + depth*15`px).
- **props**: `node: Object`(`{ id, name, count, children? }`), `selectedId: String`, `depth: Number = 0`.
- **emit**: `select(id)`.
- **주요 사용처**: `Knowledge.vue`(트리) + 자기 자신 재귀 호출.
- **비고**: 펼침 상태는 로컬 ref(최상위 depth 0 은 기본 열림). 사용 클래스 `.tree-node/.tree-row(.on)/.tree-caret(.open/.ghost)/.tree-ic/.tree-name/.tree-count`.

```html
<KnowledgeTreeNode v-for="n in tree" :key="n.id" :node="n"
  :selected-id="selected" @select="selected = $event" />
```

## 13. KnowledgeChat

- **역할**: 선택한 **내 지식(보유)을 근거로 대화하는 RAG 챗** 화면. 좌측 컬렉션 선택 범위 안에서 지식을 체크(또는 전체 선택)하고 질문하면 목(mock) 답변을 스트리밍 연출로 표시.
- **props**: `items: Array = []`(컬렉션의 내 지식), `collection: String = '전체 지식'`, `preselect: Array = []`(카드에서 진입 시 미리 선택할 지식 id).
- **emit**: 없음.
- **주요 사용처**: `Knowledge.vue`(모드 = chat).
- **비고**: 지식 미선택 시 입력/전송 비활성. 컬렉션 변경 시 선택·대화 초기화, `preselect` 변경 시 해당 지식만 선택. 사용 클래스 `.kn-chat/.kc-picker/.kc-chips/.kc-chip(.on)/.kc-card`, 채팅부는 공용 `.chat-scroll/.msg/.bubble`.

```html
<KnowledgeChat :items="myKnowledge" :collection="selectedName" :preselect="chatPreselect" />
```

## 14. ReportModal

- **역할**: 대화창에서 여는 **신고 · 개선요청 폼**. 문제 유형(도구/스킬/지식/전반) 선택 → 해당 항목 선택(또는 전체) → 요청 사항 작성. 접수 시 현재 대화 스크립트가 함께 첨부.
- **props**: `agent: Object`, `messages: Array = []`(현재 대화).
- **emit**: `close`.
- **주요 사용처**: `AgentRun.vue`(`showReport`).
- **비고**: store 액션 `submitReport`. '전반적 문제'는 항목 선택 생략. 사용 클래스 `.modal-report/.rep-cats/.rep-cat(.on)/.rep-items/.rep-item-chip(.on)/.rep-attach-note`.

```html
<ReportModal v-if="showReport" :agent="agent" :messages="msgs" @close="showReport = false" />
```

## 15. DetailModal

- **역할**: 차트/패널 **타이틀 클릭 시 상세 리스트**를 보여주는 **공용** 팝업. 두 형태 지원 — 시그널형(`events`) 또는 표형(`cols`+`rows`).
- **props**: `detail: Object` — `{ title, sub, events:[{time,sev,text}] }` **또는** `{ title, sub, cols:[…], rows:[[…]] }`.
- **emit**: `close`.
- **주요 사용처**: `ItOps.vue`, `SysMonitor.vue`, `Knowledge.vue`(문서 상세). — 시스템/지식 화면에서 폭넓게 재사용.
- **비고**: `detail.events` 존재 여부로 시그널형/표형을 자동 분기. `sev`=`critical|warning|info`. 사용 클래스 `.modal-detail/.io-detail-*`, 표는 `.io-detail-tbl`.

```html
<DetailModal v-if="detail" :detail="detail" @close="detail = null" />
<!-- 시그널형 -->
detail = { title:'최근 위험 신호', sub:'24h', events:[{time:'09:12', sev:'critical', text:'DB 지연'}] }
<!-- 표형 -->
detail = { title:'서비스 목록', cols:['이름','건수'], rows:[['A', 12], ['B', 3]] }
```

## 16. SettingsModal

- **역할**: **디자인 테마(시안) 전환** 팝업. 5개 테마를 미리보기 모형과 함께 카드로 보여주고, 클릭 즉시 전역 적용(localStorage 유지).
- **props**: 없음.
- **emit**: `close`.
- **주요 사용처**: `App.vue`(헤더 설정 버튼 → `showSettings`).
- **비고**: store 의 `setTheme(key)` 호출, 현재 테마는 `store.theme`. 테마 5종 = `default / bento / dynamic / minimal / dark`. 미리보기 색은 컴포넌트 내부 `themes[].c` 로 하드코딩(실제 토큰과 별개의 요약 색). 사용 클래스 `.modal-settings/.theme-grid/.theme-card(.on)/.tp*`.

```html
<SettingsModal v-if="showSettings" @close="showSettings = false" />
```

## 17. ApprovalLine

- **역할**: **결재선(승인 라인) 스텝퍼** — 신청자 → 1차/2차/…/최종 승인 순서를 세로로 표시하고, 결재자 추가/삭제. `v-model` 로 부모의 결재자 배열과 양방향 연결.
- **props**: `modelValue: Array = []`(결재자 `{id,name,dept,title}`), `applicant: Object`(필수), `candidates: Array = []`(추가 후보).
- **emit**: `update:modelValue(nextArray)` — 단방향 데이터 흐름(새 배열로 교체).
- **주요 사용처**: `AccessRequest.vue`(권한 신청 결재선).
- **비고**: 마지막 단계는 자동으로 '최종 승인' 라벨, 그 외 'N차 승인'. 중복 결재자는 추가되지 않음. 사용 클래스 `.line-stepper/.line-step(.applicant)/.ls-dot/.ls-body/.line-add`.

```html
<ApprovalLine v-model="approvalLine" :applicant="store.user" :candidates="APPROVER_CANDIDATES" />
```

## 18. CardRail  ⚠ 현재 미사용

- **역할**(설계): 카드 그리드 래퍼. dynamic(넷플릭스) 테마에서 좌우 화살표 + 드래그 가로 스크롤 레일을 제공하고, 그 외 테마에서는 단순 그리드로 동작하도록 만들어진 slot 래퍼.
- **props**: `grid: String = 'ax-grid'`.
- **emit**: 없음.
- **주요 사용처**: **없음** — `src/` 어디에서도 import 되지 않습니다(자기 정의뿐).
- **비고**: **미사용/데드코드**. 참조하는 CSS 클래스 `.rail / .rail-nav / .rail-track / .rail-on` 이 `styles.css` 에 **정의되어 있지 않아** 현재 상태로 붙여도 스타일이 적용되지 않습니다. 되살리려면 (1) 카탈로그에서 실제 import·사용, (2) `.rail*` 스타일 추가가 필요합니다. dynamic 테마의 가로 레일 대신 현재는 `:root[data-theme="dynamic"]` 의 다열 포스터 그리드로 처리됩니다.

## 재사용 팝업 호출 패턴 (요약)

세 가지 유형으로 팝업을 엽니다.

**A. prop 주입 + `@close`** — 로컬 상태(ref)에 데이터를 담아 `v-if` 로 렌더, 닫을 때 null.
```html
<AgentInfoModal v-if="infoAgent" :agent="infoAgent" @close="infoAgent = null" />
<DetailModal    v-if="detail"    :detail="detail"   @close="detail = null" />
<PromptDialog   v-if="show" title="새 폴더" label="폴더 이름"
  @confirm="onCreate" @close="show = false" />
```

**B. 전역 store 상태로 열기** — App.vue 에 한 번만 배치, 어디서든 store 액션으로 오픈.
```html
<!-- App.vue -->
<RequestModal v-if="store.modal" />
<DenyModal    v-if="store.denyModal" />
```
```js
openRequest('agent', agentObj)   // → store.modal 설정 → RequestModal 표시
// 닫기: store.modal = null  /  store.denyModal = null
```

**C. v-model 입력 컴포넌트** — 폼 데이터와 양방향.
```html
<ApprovalLine v-model="approvalLine" :applicant="store.user" :candidates="APPROVER_CANDIDATES" />
```

> 공통 규칙: 모든 모달은 `.overlay` 딤을 쓰고 `@click.self` 로 바깥 클릭 시 닫힘, 우상단 `.modal-close`(X) 제공. 닫기는 항상 `close` emit 또는 store 상태 초기화로 처리합니다.
