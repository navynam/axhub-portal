# AX-HUB 사용자 포털 — 퍼블리싱 가이드 (디자인 시스템)

> 대상 독자: **디자이너 · 퍼블리셔 · 초급 프론트 개발자**
> 스택: Vue 3 + Vite. 스타일은 **전역 단일 파일** `src/styles.css`(약 1,800줄) 하나로 관리합니다.
> 서체: Pretendard(웹폰트는 `index.html` 에서 jsDelivr CDN 로드).
> 이 문서는 기존 `DESIGN_GUIDE.md` 를 흡수·확장한 최신본입니다. **토큰·클래스 값은 모두 현재 `styles.css` 실제 정의 기준**입니다.
> (참고: 구 `DESIGN_GUIDE.md` 의 일부 값 — 라운드 18/14/10, canvas `#F4F7FB` — 은 옛 값이며 현재와 다릅니다. 아래 표를 신뢰하세요.)

## 0. 스타일 구조 한눈에

`src/styles.css` 는 위에서 아래로 다음 순서로 구성됩니다.

| 구역 | 내용 |
|------|------|
| `:root { … }` | **디자인 토큰**(CSS 변수) — 색/라운드/그림자/포커스 링/사이드바 폭 |
| 리셋 + `body` | 박스모델 리셋, 서체, 기본 배경/텍스트, `:focus-visible` |
| 앱 셸 | `.app` / `.sidebar`(LNB) / `.content` / `.app-header` / `.content-scroll` |
| 공통 컴포넌트 클래스 | 버튼·pill·카드·탭·칩·그리드·트리·모달·토스트·FAB 등 |
| 페이지 전용 클래스 | 홈(`.mtb-*`,`.home-*`) · 실행(`.chat-*`,`.insight-*`) · 툴관리(`.tool-*`) · 시스템(`.io-*`,`.sm-*`) |
| `@media` | 반응형 브레이크포인트 |
| `:root[data-theme="…"]` | **5개 테마 오버라이드** (토큰 재정의 + 구조 변형) |

전역 단일 파일이므로 **색을 바꾸려면 `:root` 토큰 한 곳만** 고치면 전 화면·전 테마 기본값에 반영됩니다.

## 3. 공통 클래스 카탈로그

> **실제 존재하는 클래스만** 정리합니다. 각 요소는 대부분 `<button>`/`<div>` 에 클래스를 조합해 씁니다.

### 3-1. 버튼 `.btn`

기본 `.btn` + 변형(색) + 크기 조합.

| 클래스 | 모양 | 용도 |
|--------|------|------|
| `.btn` | 높이 37px, 라운드 9px (기본 골격) | 항상 함께 사용 |
| `.btn-primary` | 신한 블루 채움 + 블루 그림자 | 1차 액션(요청 등록, 실행) |
| `.btn-accent` | 골드 채움(텍스트 `#3A2A00`) | 2차 강조 액션 |
| `.btn-green` | 그린 채움 | 승인 등 성공 액션 |
| `.btn-ghost` | 흰 배경 + 테두리 | 취소·보조 |
| `.btn-danger` | 레드 틴트 배경/텍스트 | 반려·삭제 |
| `.btn-gray` | 회색(`#6B7280`) 채움 | 중립 강조(권한 요청 등) |
| `.btn-sm` | 높이 32px | 카드/행 안 작은 버튼 |
| `.btn-block` | `width:100%` | 폭 채움 |
| `.btn:disabled` | opacity .5, 그림자 제거 | 비활성 |

```html
<button class="btn btn-primary">요청 등록</button>
<button class="btn btn-ghost btn-sm">취소</button>
<button class="btn btn-ghost btn-block fp-new"><Icon name="plus" :size="14"/> 새 폴더</button>
```

### 3-2. 상태 pill `.pill`

`.pill` 은 앞에 `::before` 로 상태 점(dot)을 자동으로 찍습니다. `flat` 을 더하면 점 제거.
색은 `StatusPill.vue` 가 권한 상태값 → 클래스로 매핑합니다(아래 4장 컴포넌트 참고).

| 클래스 | 색 | 의미 |
|--------|----|------|
| `.pill-active` | 그린 | 사용중(권한 보유) |
| `.pill-pending` | 골드 | 요청중(승인 대기) |
| `.pill-none` | 회색 | 권한없음/만료 |
| `.pill-denied` | 레드 | 반려 |
| `.pill-owner` | 블루 | 내 소유 |
| `.pill-sm` | (크기) | 20px 소형 |
| `.pill.flat` | — | 점(dot) 없는 pill |

```html
<span class="pill pill-active">사용중</span>
<span class="pill pill-pending pill-sm">요청중</span>
```

## 6. ⚠ 퍼블리셔 주의사항 (소스에서 실제 관찰됨)

1. **인라인 SVG 아이콘 색은 `currentColor`** — `Icon.vue` 의 `<svg>` 는 `stroke="currentColor" fill="none"`. 따라서 **부모의 `color`(CSS `var()` 가능)** 로 색이 정해집니다. 아이콘 색을 바꾸려면 부모 요소의 `color` 를 조정하세요(별도 fill 지정 불필요). 일부 채움형은 `svg { fill: currentColor }` 규칙으로 채웁니다(예: `.tabs .tab-ic`, `.fav-btn.on`, `.chip svg`).

2. **data-URI(문자열 안) SVG 는 CSS `var()` 미지원 → hex 하드코딩** — `.select` 의 셰브론은 `background-image: url("data:image/svg+xml,…stroke='%23626D7A'…")`. 이 색은 토큰과 무관하게 문자열에 **`#626D7A` 로 박혀 있습니다**. 토큰을 바꿔도 이 화살표 색은 안 바뀌니, 필요하면 data-URI 문자열의 `%23626D7A` 를 직접 수정하세요.

3. **토큰이 아닌 하드코딩 색이 일부 존재** — 골드 위 텍스트 `#3A2A00`, 연결방식 배지(`.proto-badge.p-*`)의 원천 시스템 색(`#2563EB`,`#9333EA` 등), 다크 테마 보정용 회색(`#212734` 등). 이들은 **의도된 예외**이므로, 브랜드 색 조정 시엔 `:root` 토큰만 바꾸고 이 하드코딩 값은 개별 확인이 필요합니다.

4. **색 변경은 반드시 `:root` 한 곳에서** — 전 화면·전 컴포넌트가 `var(--토큰)` 을 참조하므로, 토큰 하나만 고치면 일괄 반영됩니다. 개별 클래스에 색을 직접 박지 마세요.

5. **`.chip` 중복 정의** — 툴 필터용과 채팅 추천질문용 두 번 선언되어 뒤 정의가 이깁니다. 새로 `.chip` 을 쓸 땐 의도한 모양이 나오는지 확인하세요.

6. **테마별로 구조가 바뀜** — 같은 마크업(`.ax-card`)이 minimal 에선 한 줄 행, bento 에선 색면 타일이 됩니다. 새 카드 컴포넌트를 만들면 **5개 테마 모두**에서 확인하세요(특히 minimal 의 flex-row, bento 의 nth-child 색).

## 7. 퍼블리셔 작업 규칙 (styles.css 안전 수정 가이드)

- **원본은 `src/styles.css` 단 하나.** 새 CSS 파일을 만들지 말고 이 파일에 이어 쓰세요.
- **추가 위치**: 공통 컴포넌트면 관련 구역(버튼/카드/모달 등) 근처에, 페이지 전용이면 해당 페이지 구역(`.io-*`, `.mtb-*` 처럼 접두어)에 배치합니다. 접두어 네이밍(도메인-요소)을 지키면 충돌이 줄어듭니다.
- **공통화 판단**: 두 곳 이상에서 반복되면 토큰/유틸 클래스로 승격. 색은 항상 `var(--토큰)`, 라운드/그림자도 `var(--r-*)`/`var(--shadow*)` 사용.
- **테마 오버라이드가 필요하면** 파일 하단 `:root[data-theme="…"]` 블록에 추가(기본 규칙은 위쪽 공통 구역, 테마 변형은 아래쪽). `!important` 는 테마에서 기본 규칙을 덮을 때만 최소로.
- **반응형**은 가급적 기존 브레이크포인트(920/860/760px 등)에 맞춰 추가해 일관성 유지.
- **접근성**: 포커스는 `:focus-visible { outline }` + `--ring` 유지. 인터랙션 요소엔 `aria-label`/`title` 을 컴포넌트에서 이미 넣고 있으니 마크업 변경 시 보존하세요.
- 소스(컴포넌트/스토어)는 이 문서 범위가 아니며, 스타일 외 로직은 프론트 개발자와 협의하세요.
