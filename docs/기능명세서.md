# AX-HUB 사용자 포털 기능명세서 (Functional Specification)

> 대상 시스템: 신한라이프 **AX-HUB 사용자 포털** (프로토타입)
> 기술 스택: Vue 3 + Vite SPA, 목(Mock) 데이터 기반, `store` 중심 간이 라우팅
> 문서 목적: 초급 개발자·QA 가 화면별 기능을 테스트 케이스로 바로 활용할 수 있도록 실제 소스(코드/라벨) 기준으로 기능을 도출한다.
> 기준 소스: `src/App.vue`, `src/data.js`, `src/store/**`, `src/pages/**`, `src/components/**`

### 0.3 권한 상태 값 (공통)

`data.js` / `enums.js` 기준 `perm` 값:

| 값 | 라벨(pill) | 의미 |
|---|---|---|
| `owner` | 내 소유 | 내가 만든 리소스 |
| `granted` | ● 사용중 | 권한 보유 |
| `pending` | 요청중 | 승인 대기 |
| `none` | 권한없음 | 미보유 |
| `denied` | 반려 | 반려됨 |
| `expired` | 만료 | 만료(시드 표시용, 전이 로직 없음) |

> 상세 전이는 문서 말미 **권한 상태 전이표** 참고.

## 1. 홈 / 워크스페이스 (F-HOME)

### 화면 개요
- **목적**: 로그인 후 첫 진입 화면. My Agent·Work Space·현황 스탯·커뮤니티 요약을 한눈에 제공(설계서 "Main Type B").
- **접근 역할**: 사용자·관리자 공통
- **경로키**: `home` / 소스: `src/pages/Home.vue`
- **참고**: 본 화면의 목록 데이터(폴더 트리·워크스페이스 카드·스탯·커뮤니티 컬럼)는 화면 확인용 **정적 샘플**이며 store 를 읽지 않는다. 실제 동작은 대부분 `go()` 화면 이동뿐이다.

### 기능 목록

| 기능ID | 기능명 | 설명(사용자 행동→결과) | 관련 store 액션/서비스 | 상태·예외 |
|---|---|---|---|---|
| F-HOME-001 | 등록 에이전트 건수 표시 | 상단에 "등록한 에이전트 : N건"을 표시 | (정적값 `registeredCount=7`) | 고정 표시, 상호작용 없음 |
| F-HOME-002 | My Agent 검색 입력 | "Agent 검색" 입력창 노출 | 없음 | 데모 UI, 필터 미동작 |
| F-HOME-003 | My Agent 폴더 트리 | "나의 업무/미분류" 폴더와 하위 에이전트 항목 표시 | (정적 `myAgentFolders`) | 표시 전용 |
| F-HOME-004 | My Agent 항목/전체보기 이동 | 에이전트 항목 또는 "전체 보기(→)" 클릭 → 에이전트 카탈로그로 이동 | `go('agents')` | - |
| F-HOME-005 | Work Space 카드 이동 | 워크스페이스 카드 또는 "전체 보기" 클릭 → 카탈로그로 이동 | `go('agents')` | - |
| F-HOME-006 | 액션 타일 | "에이전트 직접 만들기 / 가져오기 / 즐겨찾기 2종" 타일 클릭 → 카탈로그로 이동 | `go('agents')` | 정적 타일, 실제 생성 아님 |
| F-HOME-007 | 현황 스탯 표시 | 나의 에이전트/승인된 에이전트/권한요청 지식/권한요청 도구 수치 4종 표시 | (정적 `stats`) | 고정 표시 |
| F-HOME-008 | 커뮤니티 컬럼 이동 | 우측 공지사항/커뮤니티/문의 및 오류/사용자가이드 컬럼의 항목·더보기 클릭 → 라운지로 이동 | `go('community')` | 모든 항목 `go(col.to)` |

### 데이터/상태
- 읽기: 없음(모두 컴포넌트 로컬 상수). 쓰기: 없음.
- 유일한 외부 의존: `go(page)` (세션 모듈)로 화면 전환.

### 연계
- 대부분의 클릭이 `agents`(카탈로그) 또는 `community`(라운지)로 이동.

## 2. 에이전트 카탈로그 (F-AGT)

### 화면 개요
- **목적**: 에이전트 검색·필터·즐겨찾기·폴더 그룹화·실행/권한요청. 핵심 규칙: "에이전트는 누구나 사용 가능하지만, 활용 **도구**를 모두 보유해야 실행 가능".
- **접근 역할**: 사용자·관리자 공통
- **경로키**: `agents` / 소스: `src/pages/Agents.vue`

### 기능 목록

| 기능ID | 기능명 | 설명(사용자 행동→결과) | 관련 store 액션/서비스 | 상태·예외 |
|---|---|---|---|---|
| F-AGT-001 | 탭 전환(내/전체/즐겨찾기) | [내 Agent]=소유, [전체 Agent]=타 에이전트+활성 소유, [즐겨찾기]=별표한 것으로 목록 전환. 각 탭 개수 배지 표시 | `store.agents` 필터 | 즐겨찾기 비었으면 전용 빈상태 |
| F-AGT-002 | 키워드 검색 | "Agent 검색" 입력 → 이름·설명·소유 부서 부분일치 필터 | 로컬 `q` | 공백 무시 |
| F-AGT-003 | 상태 필터 | 셀렉트 [상태 전체/실행 가능/도구 권한 필요]로 필터 | `agentReady`, `resourcePerm` | 실행가능=도구 전부 보유+(소유는 활성) |
| F-AGT-004 | 보기 전환(카드/리스트) | 그리드/리스트 아이콘 토글 | 로컬 `view` | - |
| F-AGT-005 | 폴더 칩 필터 | [전체]+폴더칩 클릭으로 폴더별 필터. 폴더별 개수 표시 | 로컬 `folderFilter` | '전체'는 폴더별 섹션 그룹화 |
| F-AGT-006 | 새 폴더 생성 | [+ 새 폴더] → PromptDialog 입력 → 폴더 생성 후 해당 폴더로 필터 전환 | `addFolder(name)` | 빈 이름/중복은 무시 |
| F-AGT-007 | 해시태그(도구) 필터 | 도구명 해시태그 클릭 → 해당 도구 사용 에이전트만. 재클릭/[초기화]로 해제 | 로컬 `tagFilter` | 토글식 |
| F-AGT-008 | 공유순 정렬 | 목록을 공유 횟수(`shares`) 내림차순 정렬 | (파생) | 자동 |
| F-AGT-009 | 즐겨찾기 토글 | 카드 별(★) 클릭 → 즐겨찾기 추가/해제 + 토스트 | `toggleFavorite(agent)` | 카드/리스트 양쪽 제공 |
| F-AGT-010 | 활성/비활성 토글 | 소유 에이전트의 토글 스위치 → 활성/비활성 + 토스트 | `toggleActive(agent)` | 소유(`perm==='owner'`)만 노출 |
| F-AGT-011 | 폴더 이동 | 카드의 폴더 버튼 클릭 → FolderPickerModal 열림 | `moveAgentToFolder`(모달) | F-AGT-101~ 참고 |
| F-AGT-012 | 에이전트 정보 보기 | 카드 본문(또는 리스트 ≡) 클릭 → AgentInfoModal 열림 | (모달) | Enter 키도 지원 |
| F-AGT-013 | 실행 | 도구 전부 보유 시 [실행] 클릭 → 대화 화면 진입 | `openRun(agent)` | 소유+비활성이면 버튼 disabled |
| F-AGT-014 | 요청중 표시 | 미보유 도구가 전부 '요청중'이면 [요청중] disabled 버튼 | `resourcePerm` | 클릭 불가 |
| F-AGT-015 | 권한 요청 | 미보유 도구 있으면 [권한 요청] → 권한요청 모달(RequestModal) | `openRequest('agent', a)` | 도구 일괄 요청 |

### 데이터/상태
- 읽기: `store.agents`(id/name/desc/owner/perm/active/fav/folder/shares/tools/…), `store.folders`, `store.resources`.
- 쓰기: `toggleFavorite`/`toggleActive`(agent 필드), `addFolder`(store.folders), 폴더 이동·권한 요청(모달 경유).
- 파생 규칙: `isRunnable = agentReady(a) && (perm!=='owner' || active)`, `agentPending`(미보유 도구가 모두 pending), `folderList`, `sections`(폴더 그룹).

### 연계
- [실행]→ `run`(3장). [권한 요청]→ RequestModal. 카드 클릭→ AgentInfoModal. 폴더 버튼→ FolderPickerModal. [새 폴더]→ PromptDialog.

## 14. 권한 상태 전이표

에이전트·지식(대상 `item.perm`)과 리소스(도구·미들웨어·스킬·MCP, `store.resources[name].perm`)에 공통 적용된다.

### 14.1 상태 전이

| 현재 상태 | 이벤트(트리거) | 다음 상태 | 실행 액션 | 부수효과 |
|---|---|---|---|---|
| `none` | 권한 요청 제출 | `pending` | `submitRequest` / `requestResource` | 요청(request) 생성, 승인자 전달 토스트 |
| `denied` | 재요청 | `pending` | `submitRequest` / `requestResource` | 새 요청 생성(재요청 라벨) |
| `expired` | 재요청 | `pending` | (요청 흐름 동일) | 시드 표시 상태, 별도 만료 로직 없음 |
| `pending` | (관리자) 승인 | `granted` | `approve` | 요청 status=approved, ABAC 반영 토스트, 관련 에이전트 실행 가능화 |
| `pending` | (관리자) 반려 | `denied` | `confirmDeny` | 요청 status=denied, denyReason 저장, 요청자 전달 |
| `pending` | (사용자) 요청 취소 | `none` | `cancelRequest` | 요청 목록에서 제거 |
| `pending` | (관리자) 일괄 승인 | `granted` | `approveAll`→`approve` | 대기 요청 전부 승인 |
| `granted` | (재요청 시도) | `granted` | `requestResource` 무시 | granted/pending 은 재요청 차단 |
| `owner` | — | `owner` | — | 소유 리소스는 전이 없음(항상 사용 가능) |

### 14.2 비고
- **요청 대상 유형**: `agent`(→ 활용 도구 일괄 요청), `knowledge`(→ 지식 자체), `resource`(→ 개별 도구). 에이전트 권한 요청은 실제로는 **미보유 도구(none/denied)** 들을 일괄로 `pending` 전환한다.
- **승인 반영 대상**: `approve`/`confirmDeny` 는 `targetType==='resource'` 면 `store.resources[name].perm` 를, `mine` 인 agent/knowledge 요청이면 대상 `item.perm` 를 변경한다.
- **실행 가능 판정**: 에이전트 실행 가능(`agentReady`)은 에이전트 자체 perm 이 아니라 **활용 도구가 전부 `granted`** 인지로 결정된다(소유 에이전트는 추가로 `active` 필요).
- **신고(개선요청) 상태**(권한과 별개): `received → in_progress → answered → resolved`. 사용자는 `received` 에서만 취소 가능, 관리자는 진행 시작/답변/개선 완료 처리.
