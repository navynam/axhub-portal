# Figma 연동 가이드 — 페이지를 편집 가능한 레이어로 임포트

> 목적: AX-HUB의 **완성된 화면 전체**를 Figma에서 **레이어 단위로 편집 가능**하도록 가져온다.
> 방법: 각 화면을 **자체 완결형 HTML**(CSS 인라인·스크립트 제거)로 스냅샷한 뒤, Figma **html.to.design** 플러그인으로 임포트한다.

> ⚠ 참고: Figma는 REST API로 디자인(프레임/레이어)을 **직접 생성할 수 없습니다.** 디자인 생성은 Figma 내부에서 도는 플러그인만 가능하므로, "코드 → Figma"는 아래 플러그인 임포트 방식으로 연동합니다.

---

## 1. 생성물 (`figma-export/`)

**테마 3종 × (화면 · 팝업 · 공통메세지)** 구조로, 테마 폴더 단위로 Figma에 올릴 수 있습니다.

```
figma-export/
├─ index.html            썸네일 갤러리(브라우저로 열기)
├─ _generate.mjs         재생성 스크립트(아래 5장)
├─ default/   신한 기본  ┐
├─ bento/     베토 그리드 ├─ 테마별 폴더
└─ dark/      다크        ┘
     ├─ pages/     <name>.html + <name>.png   화면 13종
     ├─ popups/    <name>.html + <name>.png   팝업 11종
     └─ messages/  <name>.html + <name>.png   공통 메세지(토스트)
```

각 `.html`은 **자체 완결형**(CSS 인라인·`<script>` 제거·1440px)이며 **dev 서버 없이도 브라우저에서 그대로 렌더**됩니다(3테마 전부 검증 완료 — 다크/베토 색·아이콘·차트 SVG 정상). `.png`는 미리보기입니다.

**화면(pages, 13):** home · agents · tools · run · knowledge · glossary · community · perms · access · sysmon · itops · computeruse · daily

**팝업(popups, 11):** settings-theme(설정·테마) · settings-keys(설정·KEY 관리) · agent-info(에이전트 정보) · request-permission(권한 요청) · new-folder(공통 입력) · folder-move(폴더 이동) · report(신고·개선요청) · detail(상세 정보) · deny(반려 사유) · builder(Agent 빌더 런처) · chatbot(챗봇)
> 팝업 HTML은 딤 처리된 페이지 위에 모달이 올라간 상태로 캡처됩니다. Figma 임포트 후 `.overlay` 레이어 그룹이 곧 팝업입니다.

**공통 메세지(messages, 1):** toast(우하단 토스트 알림)

> 테마별로 총 25종 × 3테마 = **75개 HTML**. 특정 상태(다른 탭·다른 토스트 등)가 더 필요하면 `_generate.mjs` 의 `POPUPS`/`MESSAGES` 에 트리거를 추가해 재생성하세요.

## 2. 준비 — html.to.design 플러그인

1. Figma에서 **Community → 플러그인**에서 **`html.to.design`** 설치. (URL·HTML을 Figma 레이어로 변환하는 대표 플러그인)
2. 대안: `Builder.io`(Import) 플러그인도 동일 원리로 사용 가능.

---

## 3. 임포트 방법

### 방법 A — HTML 코드 붙여넣기 (오프라인, 이 파일들에 권장)

1. `figma-export/<테마>/<카테고리>/<이름>.html`(예: `dark/pages/itops.html`, `bento/popups/report.html`)을 텍스트 에디터(VS Code 등)로 열어 **전체 선택 → 복사**.
2. Figma에서 `html.to.design` 실행 → **Import** → **Paste HTML(코드 붙여넣기)** 선택.
3. 복사한 HTML을 붙여넣고 **Import** 클릭.
4. 각 요소가 레이어로 생성됩니다:
   - `<div>` → **Frame**(오토레이아웃 추정)
   - 텍스트 → **Text 레이어**
   - 인라인 `<svg>`(아이콘·차트) → **Vector**
   - 배경·보더·그림자 → **Fill / Stroke / Effect**

### 방법 B — URL 임포트 (충실도 더 높음)

플러그인은 URL을 직접 렌더해 가져올 때 레이아웃 정확도가 가장 높습니다.

1. 로컬에서 폴더를 서빙:
   ```bash
   npx serve figma-export        # 또는 VS Code "Live Server"
   ```
2. `html.to.design` → **Import web URL** 에 `http://localhost:3000/<테마>/<카테고리>/<이름>.html` 입력 → Import.
3. (선택) 사내/공개 정적 호스팅에 `figma-export/` 를 올리면 팀원이 URL로 공유·임포트할 수 있습니다.

> SPA 특성상 실서비스 URL(navynam.github.io/axhub-portal)은 **화면별 주소가 없어** 홈만 잡힙니다. 그래서 **화면별 HTML 파일**을 쓰는 것이 정확합니다.

## 4. 임포트 후 정리 팁 (디자이너)

- **컴포넌트화**: 반복되는 카드·버튼·pill·칩을 Figma **Component**로 승격 → 배리언트 정리.
- **오토레이아웃 점검**: 플러그인이 추정한 오토레이아웃을 방향/간격 기준으로 다듬기(카드 그리드는 Wrap).
- **네이밍**: 프레임 이름을 화면/영역 기준으로 정리(LNB, 헤더, 카드그리드 등).
- **색·타이포 스타일**: 아래 디자인 토큰을 Figma 스타일/변수로 등록해 재사용.
- **화면 정렬**: 13개 프레임을 한 페이지(예: "AX-HUB / Screens")에 그리드로 배치.

### 디자인 토큰(참고)
색·간격·라운드·그림자는 코드에서 `src/styles.css` 의 `:root` 변수 **한 곳**에서 관리합니다(예: `--navy #0046FF`, `--accent #C6982E`, `--r-md`, `--shadow`). 전체 목록은 [퍼블리싱가이드](퍼블리싱가이드.md) 참고. 토큰을 Figma **Variables**로 자동 동기화하려면 **Tokens Studio(Figma Tokens)** 플러그인 + 토큰 JSON을 별도로 운용할 수 있습니다(필요 시 내보내기 지원 가능).

## 5. 재생성 (화면이 바뀌면)

코드/화면을 수정한 뒤 스냅샷을 갱신합니다.

```bash
# 1) dev 서버 실행
npm run dev            # http://localhost:5173

# 2) (다른 터미널) 스냅샷 재생성
node figma-export/_generate.mjs
```

- `figma-export/html/*.html`, `preview/*.png`, `index.html` 이 최신 화면으로 다시 생성됩니다.
- 이후 Figma에 **재임포트**하면 반영됩니다. (플러그인은 기존 레이어를 자동 병합하지 않으므로, 새 프레임으로 가져와 교체하는 방식 권장)

### 특정 상태로 캡처하고 싶다면
임포트는 **정적 스냅샷**이라 모달 열림·특정 탭 선택 등 상태는 캡처 시점 기준입니다. 예를 들어 "설정 → KEY 관리 탭" 화면이 필요하면, `_generate.mjs` 의 해당 `nav`에 클릭 단계를 추가한 뒤 재생성하세요.

## 6. 방향 요약

| 방향 | 방법 | 비고 |
|---|---|---|
| **코드 → Figma** (이 문서) | 화면별 self-contained HTML → html.to.design 임포트 | 편집 가능한 레이어로 변환 |
| 디자인 토큰 동기화 | styles.css `:root` → Tokens Studio 변수 | 색·간격·타이포 일관성 |
| **Figma → 코드** (역방향) | Figma **Dev Mode MCP** 연결 | 디자인을 코드에서 읽어 반영(추후 옵션) |
