# AX-HUB 문서 인덱스

신한라이프 **AX-HUB 사용자 포털** 프로젝트 문서 모음입니다.
아래 순서대로 읽으면 기획 → 기능 → 구조 → 개발/퍼블 → API 순으로 전체를 파악할 수 있습니다.

## 읽는 순서 (역할별 추천)

| 역할 | 추천 경로 |
|---|---|
| **기획자 / PM** | 기획서 → 기능명세서 |
| **초급 개발자(온보딩)** | 개발가이드 → 아키텍처 → 기능명세서 → API명세서 |
| **디자이너 / 퍼블리셔** | 퍼블리싱 가이드 → 컴포넌트 카탈로그 → 기획서 |
| **백엔드 개발자** | 백엔드 가이드 → API명세서 → 아키텍처 |

## PowerPoint(.pptx) 버전

위 문서들의 발표용 PPT 변환본이 [`docs/pptx/`](pptx/) 에 있습니다(신한 브랜드 톤, 표·목록·다이어그램 소스 포함).
마크다운 수정 후 재생성: `python docs/_md2pptx.py` (python-pptx 필요).

## 문서 유지 규칙

- 소스가 바뀌면 관련 문서도 같은 PR에서 갱신합니다. (특히 화면 추가/삭제 → 기획서·기능명세서·아키텍처)
- 모든 문서는 **실제 소스(`src/`, `backend/`)를 근거**로 하며, 소스와 문서가 다르면 **소스를 우선**합니다.
- 문서 최상단에 "기준 소스 · 기준일"을 명시합니다.

> 프로젝트 개요와 빠른 시작은 리포지토리 루트 [README.md](../README.md) 를 참고하세요.
